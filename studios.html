Comment ça marche

En ligne en trois étapes

  1. 1

    Étape 1 : Créez votre boutique

    Importez vos visuels et composez votre boutique avec l'éditeur visuel : cartes, couleurs, prix, abonnements. Aucune compétence web requise.

  2. 2

    Étape 2 : Intégrez en une journée

    Branchez le SDK (JavaScript, Unity) ou recevez un webhook signé sur votre serveur. Vos joueurs lient leur compte de jeu une seule fois, avec un code affiché en jeu.

  3. 3

    Étape 3 : Le jeu se met à jour tout seul

    Vos joueurs achètent sur le web, moins cher. Dev AppStore livre l’achat au jeu automatiquement, en quelques secondes, sans action de leur part.

Sécurité et fiabilité

Chaque achat arrive dans le jeu, une seule fois

La livraison automatique est le cœur de Dev AppStore : vos joueurs n'ont rien à faire, et vous gardez le contrôle.

  • Webhooks signés HMAC

    Chaque livraison porte une signature horodatée (en-tête DevAppStore-Signature) que votre serveur vérifie avant de créditer : impossible de forger un achat.

  • Livraison garantie

    Si votre serveur ne répond pas, Dev AppStore relance automatiquement pendant 24 h et plus. Le SDK récupère aussi les achats en attente au lancement du jeu.

  • Jamais de double crédit

    Chaque livraison a un identifiant unique servant de clé d'idempotence, et le jeu confirme la réception (ack). Vous suivez chaque statut dans le journal.

  • Paiements sécurisés

    Les paiements sont traités par Stripe : Dev AppStore ne stocke jamais les numéros de carte. Les reversements arrivent sur votre compte via Stripe Connect.

FAQ

Questions fréquentes

Est-ce compatible avec les règles d’Apple et de Google ?+

Les règles des stores sur les achats effectués en dehors de l’application varient selon les pays et évoluent régulièrement (décisions de justice, réglementations comme le DMA en Europe). Dans de nombreux cas, un joueur peut acheter sur le web un contenu qu’il retrouve ensuite dans le jeu ; en revanche, la possibilité de mentionner ou de lier ce site depuis l’application dépend de votre région et de votre programme.

À vérifier selon votre région : consultez les conditions en vigueur d’Apple et de Google, et si besoin votre conseil juridique, avant de communiquer sur Dev AppStore dans votre jeu.

Combien coûte Dev AppStore ?+

Aucun abonnement ni frais d’installation : Dev AppStore prélève une commission de 5 % sur chaque vente, contre 15 à 30 % sur les stores selon votre programme (15 % pour les petits studios et les abonnements après un an, 30 % au taux standard). Vous gardez donc environ 95 % du prix payé par le joueur (hors taxes applicables).

Dois-je retirer mes achats in-app des stores ?+

Non. Dev AppStore vient en complément : vos joueurs gardent le choix d’acheter dans l’application ou sur le web, où vous pouvez proposer un meilleur prix. Le calculateur ci-dessus vous permet d’estimer l’effet d’une bascule partielle.

Combien de temps prend l’intégration ?+

Une journée en général : un point d’entrée webhook (ou quelques lignes de SDK) pour créditer le joueur, et l’affichage d’un code de liaison dans le jeu. Un jeu de démonstration et des clés de test sont fournis.

Comment le joueur relie-t-il son compte de jeu ?+

Une seule fois par jeu : le jeu affiche un code temporaire que le joueur saisit sur Dev AppStore, ou le joueur indique son identifiant et confirme son pseudo. Ensuite, chaque achat est livré automatiquement sur le bon compte.

Quand suis-je payé ?+

Les reversements passent par Stripe Connect, selon le calendrier de versement de votre compte Stripe. Vous suivez vos ventes et tendances dans l’espace studio.
